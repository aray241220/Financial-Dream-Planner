1. PROJECT SUMMARY
------------------------------------------------------------
A fully local, beginner-friendly academic project that:
- Predicts a fresher's FUTURE SALARY using ML.
- Projects inflation-adjusted costs for 3 goals: Marriage, Car, Home.
- Computes required monthly SIP investment per goal.
- Reports savings capacity, surplus/shortfall and feasibility.
- Serves a clean dashboard via FastAPI.

Stack: Python, FastAPI, pandas, NumPy, scikit-learn, Joblib,
HTML/CSS/JavaScript. No RAG, no paid APIs, no cloud.

------------------------------------------------------------
2. HARD CONSTRAINTS (MUST HONOR)
------------------------------------------------------------
[ ] No RAG, paid APIs, or cloud services.
[ ] EXPERIENCE is NOT a feature (all users are freshers).
[ ] ML target = Future Salary (5-yr). Features = Age, City, Current
    Salary (City one-hot). Trained on synthetic salary_growth.csv
    (generated + documented). Experience not used.
[ ] City encoded properly (OneHotEncoder inside sklearn Pipeline).
[ ] Fixed random_state for train/test split.
[ ] Two models: Linear Regression + Decision Tree Regressor.
[ ] Evaluate with MAE and R2.
[ ] Selection rule: lower MAE first, higher R2 as tie-breaker.
[ ] Save pipeline with Joblib; load once, never retrain per request.
[ ] Inflation fixed 6%: Future Cost = Current Cost * (1.06)^Years.
[ ] No hard-coded city costs (read from CSV).
[ ] No fake ML accuracy, no guaranteed financial claims.
[ ] Include educational-simulation disclaimer everywhere relevant.

------------------------------------------------------------
3. DOCUMENTED ASSUMPTIONS (DEFAULTS)
------------------------------------------------------------
A. Salary basis: model predicts 5-YEAR Future Salary from Age, City,
   Current Salary (trained on synthetic salary_growth.csv). Per-goal
   salary uses the implied CAGR (current -> predicted future over
   5 yrs). Capacity uses the user's CURRENT salary.
B. Investment return: 12% annual (assumption, not guarantee).
   monthly rate i = 0.12/12; months n = years * 12.
   Contribution timing: start of month (annuity-due).
C. Required SIP (solve annuity-due FV for P):
   P = (FV * i) / (((1+i)^n - 1) * (1+i))
D. Saving capacity = user's Current Salary * Saving% (matches the
   spec example; no double-counting with predicted future salary).
E. Feasibility thresholds:
   - Surplus >= 0                 -> Achievable
   - Shortfall <= 25% of capacity -> Challenging
   - Larger shortfall             -> Highly Challenging
F. City costs carry an Area_Type dimension (10 types/city). DECISION:
   default to a single area type (e.g., "Central") unless the user
   selects one; costs always read from CSV (never hard-coded).
