# Demonstration Video Script

**Project:** AI-Powered Financial Goal Planner & Salary Growth Predictor
**Target length:** ~4–5 minutes
**Setup before recording:** open a terminal in the project root
(`.../Assignment`), close other noisy apps, and have the browser ready. Run each
command as shown. Speak the **SAY** lines; do the **DO** actions.

> Tip: keep `python -m` prefixes — the packages' Scripts folder isn't on PATH.

---

## Scene 1 — Intro (0:00–0:30)

**DO:** Show the project folder in VS Code (expand `app/`, `data/`, `tests/`).

**SAY:**
> "Hi, this is my final capstone — an AI-Powered Financial Goal Planner and
> Salary Growth Predictor. It's a fully local app: no cloud, no paid APIs, no
> RAG. A fresher enters their salary and goals — marriage, car, and home — and a
> machine-learning model predicts their future salary while a planning engine
> works out the cost, the monthly investment needed, and whether the plan is
> feasible. Everything you'll see runs on my laptop."

---

## Scene 2 — The data (0:30–1:00)

**DO:** Open `data/salary_growth.csv` and `data/city_goal_costs.csv`.

**SAY:**
> "There are two datasets. `salary_growth.csv` has Age, City, Current Salary and
> Future Salary — that's the training data. `city_goal_costs.csv` holds the
> current cost of each goal per city and area type. The Future Salary column is
> a documented, synthetic 5-year target, generated by this script —" **(DO: open
> `data/generate_salary_growth.py`)** "— so the ML task is genuine but the data
> is clearly labelled as illustrative."

---

## Scene 3 — Train the model (1:00–1:45)

**DO:** Run:
```powershell
python -m app.ml.train
```

**SAY (while it runs):**
> "I train two models — Linear Regression and a Decision Tree Regressor — inside
> a scikit-learn pipeline that one-hot encodes City. Both are evaluated with MAE
> and R². The selection rule is documented: lowest MAE wins, with R² as the
> tie-breaker."

**DO:** Point at the output.

**SAY:**
> "Linear Regression wins here — MAE about 3,800 rupees and R² 0.99. The trained
> pipeline is saved to `models/salary_model.joblib` with Joblib, and the app
> loads it once — it never retrains per request."

---

## Scene 4 — Start the app (1:45–2:05)

**DO:** Run:
```powershell
python -m uvicorn app.main:app --reload
```
Then open http://127.0.0.1:8000 in the browser.

**SAY:**
> "The backend is FastAPI. I'll start the server and open the dashboard."

---

## Scene 5 — A tight plan (2:05–3:00)

**DO:** Fill the form:
Name `Shyam`, Age `22`, City `Bangalore`, Area type `North`, Salary `165000`,
Saving `25`, Marriage `10`, Car `5`, Home `8`. Click **Build my plan**.

**SAY:**
> "I'll enter a profile — a 22-year-old in Bangalore earning 1.65 lakh a month,
> saving 25%, with marriage in 10 years, a car in 5, and a home in 8."

**DO:** Point to each result card.

**SAY:**
> "The model predicts a 5-year future salary of about 2.7 lakh. Each goal shows
> its current cost, the cost inflated at a fixed 6% per year, and the monthly SIP
> needed — using an annuity-due formula with a documented 12% assumed return. The
> combined requirement is about 1.12 lakh a month, but the saving capacity is
> only about 41,000, so there's a shortfall — the plan is flagged **Highly
> Challenging**, in red."

---

## Scene 6 — Make it feasible (3:00–3:40)

**DO:** Change inputs to something comfortable — e.g. Salary `300000`,
Saving `60`, Marriage `15`, Car `18`, Home `25`. Click **Build my plan** again.

**SAY:**
> "The PDF asks that users can change their saving rate or timelines and
> recalculate. If I raise the salary and saving percentage and stretch the
> timelines, the required SIP drops, capacity rises, and the same plan turns
> **Achievable**, in green, with a monthly surplus. The feasibility thresholds are
> documented: surplus is Achievable, a shortfall within 25% of capacity is
> Challenging, and anything larger is Highly Challenging."

---

## Scene 7 — Validation & API (3:40–4:20)

**DO:** In the form, type an out-of-range value (e.g. saving `150`) and submit to
show the friendly error. Then open http://127.0.0.1:8000/docs, expand
`POST /plan`, and run a request.

**SAY:**
> "Inputs are validated with Pydantic and return clear messages — here saving
> percentage must be between 0 and 100. And because it's FastAPI, there's an
> auto-generated API at `/docs`. The `/plan` endpoint takes the profile as JSON
> and returns the full plan — ML prediction and financial calculations are kept
> in separate, reusable modules."

---

## Scene 8 — Tests (4:20–4:45)

**DO:** In a second terminal, run:
```powershell
python -m pytest -q
```

**SAY:**
> "Finally, the project is tested — 24 unit and API tests covering the inflation
> and investment math, the feasibility bands, and the endpoints. All pass."

---

## Scene 9 — Close (4:45–5:00)

**SAY:**
> "So that's the full pipeline — data, a trained and selected ML model, the
> financial engine, a validated API, and a dashboard, all running locally. And to
> be clear, this is an educational simulation: the inflation, return and salary
> assumptions don't guarantee any real financial outcome. Thanks for watching."

---

## Quick command reference

```powershell
# (optional) regenerate the synthetic training set
python data/generate_salary_growth.py

# train + save the model
python -m app.ml.train

# run the app  ->  http://127.0.0.1:8000  (API docs: /docs)
python -m uvicorn app.main:app --reload

# run tests
python -m pytest -q
```
